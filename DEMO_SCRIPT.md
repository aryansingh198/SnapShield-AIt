# SnapShield AI — Demo Script

## 60–90 second demo

### 1. Open the application
Say:

> “This is SnapShield AI, a private on-device scam and phishing detector.”

### 2. Paste a suspicious example

```text
Urgent! Your bank account will be blocked.
Verify your password and OTP now.
```

Click **Analyze Locally**.

### 3. Explain the result

Point to:
- risk level
- score
- detected risk language
- sensitive authentication request

Say:

> “The important part is not only the score. SnapShield tells the user why the message was flagged.”

### 4. Demonstrate a normal message

Use:

```text
The project meeting has moved to three pm.
```

Run the analysis again and show the different risk result.

### 5. Close with the Snapdragon story

Say:

> “The current prototype is local-first. Its compact model boundary is designed for a future ONNX-based optimization and profiling path on a Snapdragon-powered HP PC.”

## Do not claim

- measured Snapdragon performance unless you actually measured it
- production-grade security accuracy
- that the model detects every scam
