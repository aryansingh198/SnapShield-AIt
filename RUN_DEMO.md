# Run the working demo

## Fastest visual demo
Open `index.html` in Chrome/Edge/Firefox.

Try:
`Urgent! Your bank account will be blocked. Verify your password and OTP now.`

Then click **Analyze Locally**.

## Main Python prototype
On a laptop with Python installed:

```bash
pip install -r requirements.txt
python app.py
```

Windows users can also run `run.bat`.

The Python version is the main ML prototype. The browser version is a zero-install presentation/demo layer.
